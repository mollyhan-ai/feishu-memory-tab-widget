# 可切换资料卡片生成器

这是一个可安装的 Codex Skill 和飞书云文档小组件原型。它把一段资料整理成任意数量的“标题 + 内容”卡片，并支持点击标题切换当前内容。

推荐 Skill 标题：

**可切换资料卡片生成器**

英文标识为 switchable-content-cards。这个名字不绑定某一类资料，也不把能力限制为固定 5 张卡片，适合以后处理产品需求、访谈、课程笔记、研究资料和其他文本。

## 目前能力

- 卡片数量由资料决定，不固定为 5 张
- 每张卡片包含一个标题和一段内容
- 支持横向胶囊、分段栏、侧边栏三种展现形式
- 支持鼠标点击、键盘方向键、Home 和 End 切换
- 支持 URL 和本地状态保存
- 在飞书宿主中优先使用 Record 保存当前卡片，并自动更新组件高度
- 构建后生成单文件 dist/index.html

## 本地测试

先编辑 content.json，再运行：

    npm test
    npm run build

然后在项目目录启动静态服务，打开 dist/index.html。当前 content.json 只是示例，下一步会替换成你提供的测试资料。

## Skill 使用方式

用户可以把仓库安装为 Skill，然后输入：

    使用可切换资料卡片生成器，把下面这段资料做成可以点击切换的卡片：
    ……

如果用户没有指定版式，Skill 会先询问横向胶囊、分段栏或侧边栏。用户确认生成结果后，才进入导出、飞书接入或 GitHub 更新。

## 飞书说明

普通复制粘贴无法可靠地把 JavaScript 交互带进飞书文档。要在飞书文档内保留切换效果，需要把 dist/index.html 作为飞书云文档小组件的前端资源接入，并完成飞书开放平台的应用配置。没有小组件权限时，可使用静态降级版或插入交互页面链接。
